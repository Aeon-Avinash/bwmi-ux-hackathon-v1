C3

Clock badges — only honest time

.clk · .clk-age · .clk-deadline · .clk-target · .clk-done

Four clocks, nothing else. ELAPSED counts since report (neutral). AGE counts since a card's own source timestamp (violet). DEADLINE appears only with a written rule behind it (crimson). TARGET is our bar, always labelled ours (blue).

ELAPSED · 36 hrs AGE · 33 hrs DEADLINE · by Tue 1 Sep, 9:34 PM TARGET · OURS [PROPOSED] · 48 hrs recorded 9:58 AM
Do: carry a citation on every DEADLINE (“cited: helpline SOP”) and “OURS” on every TARGET.
Don't: animate, pulse, or count down any clock. No SLA theatre — time here reads, it doesn't tick at you.

Money-state chips

.mchip .mchip-held / -asked / -moved / -unknown / -returned

The per-institution state of the money, machine code kept intact as code. An asked hold is visibly not a hold: dashed vs solid tells the story before reading.

Don't: translate codes into friendlier codes. Plain sentences translate; chips don't.
